1. Been back solving leetcode since I'm applying for a Frontend Developer at IBM. For this problem, I used 3 pointers: 1 pointer to point where the last non-zero integer in the nums1 array. Another pointer to point where the last non-zero integer in the nums2 array. And another pointer to point to the last index of the nums1 array. The algorithm is that the two pointers compares the two numbers from each array and compares which is bigger. Whichever number is bigger, the pointer of the array from which that number is taken from decrements by 0 thus making the pointer point to the next array in sequence.
